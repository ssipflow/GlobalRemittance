# JWT 클레임 유지 결정

- 날짜: 2026-10-20, 사용자 결정.
- 결정: 토큰 payload를 요구사항(`docs/requirements/project-goals.md`)대로 유지한다(DB id, userId, name, expireTime, 표준 iat/exp/sub).
- 이유: 요구사항이 명시한 사양이며 토큰은 서명되고 30분 뒤 만료된다. 최소화(이름·이메일 제거 후 필요 시 DB 조회)는 요구사항 변경이 필요한데 얻는 이득이 크지 않다고 판단했다.
- 주의: JWT payload는 서명되지만 암호화되지 않아 토큰을 가진 쪽은 이름·이메일을 읽을 수 있다. 토큰을 로그·URL에 남기지 않는 기존 규칙을 유지한다.
- 재검토 조건: 요구사항이 바뀌거나 payload에 민감 정보를 더 넣어야 할 때.
