# 개선 백로그

아래는 초기 조사에 기반한 진단 대상이다. 코드 결함으로 확정한 목록이 아니다.

| 우선순위 | 작업 | 완료 기준 |
| --- | --- | --- |
| P0 | 테스트 실행 환경 격리와 기준선 확보 | 사용자 홈 DB를 쓰지 않고 외부 API 없이 반복 실행; 실제 성공/실패 기록 |
| P1 | 송금 정확성/동시성 진단 | 금액, 수수료 경계, 중복 접수, 동시 한도 초과, 만료의 근거와 회귀 테스트 |
| P1 | 인증/소유권/비밀 관리 진단 | 잘못된 토큰과 타인 견적 접근 검증, 민감정보 노출 여부 확인 |
| P2 | 클린 아키텍처로 점진적 이전 | 도메인 규칙/유스케이스/포트/어댑터 경계 분리; 내부의 기술 의존성 제거; 동작 회귀 없음; 설계 근거 기록 |
| P2 | CI와 실행 문서 | 동일 검증 명령으로 재현; 새 개발자가 문서만으로 실행 가능 |
| P3 | 운영 가능성과 포트폴리오 설명 | 필요한 로그/오류 처리/성능 근거, 아키텍처와 선택의 비용을 문서화 |
