# obsidian-workflow

- 요청: 개발 컨벤션·Git 전략을 유지하고 옵시디언 문서화 절차만 추가.
- 배경: 향후 목표를 처음부터 다시 개발하는 방향으로 변경할 예정.
- 범위: 지침 로딩 연결, 문서화 단계·원본 기준·검증/PR 연결·중단/재개·미설정 처리.
- 제외: 목표 확정, 코드 변경, Vault 연결, 플러그인/동기화 구축.
- 옵시디언 반영: Vault/프로젝트 폴더 미설정. 실제 노트 쓰기 미실행.
- 완료 기준: 독립 문서 리뷰, 지침 경로 확인과 git diff --check 후 dev PR 생성.
- 종료: 하네스 커밋·작업 브랜치 push·PR. 승인과 병합은 사람.
