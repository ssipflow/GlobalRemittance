# obsidian-sync

- 목표: 개인 Vault의 프로젝트 전용 폴더와 저장소 문서를 단방향으로 연결.
- 범위: 로컬 연결 설정, 명시적 동기화 CLI, 사용자 노트 보존, 회귀 검증, 에이전트 절차.
- 원본: 저장소 기억/결정과 실제 Git·하네스 PR 기록. Vault는 요약·링크를 제공.
- 연결 설정: Git에서 무시되는 .harness/obsidian.json. 개인 경로는 tracked 문서에 기록하지 않는다.
- 실행 시점: 작업 시작·중단·커밋 전·PR 생성 후 Coordinator가 명시적으로 sync.
- 완료 기준: 프로젝트 폴더 밖 쓰기 거부, 사용자 구역 보존, 반복 실행 중복 없음,
  임시 Vault 회귀 테스트, 실제 프로젝트 노트 쓰기와 읽기 확인, 독립 리뷰·검증, dev PR.
- 제외: Vault 전체 탐색, 개인정보 수집, Vault Git 커밋/push, 감시 프로세스, 양방향 동기화.
- 개발 목표: 새 목표 확정을 기다린다. 기존 개선 백로그는 실행하지 않는다.
- 현재 연결: 사용자가 지정한 Vault의 프로젝트 전용 폴더를 로컬 설정으로 연결했다.
  최초 프로젝트 개요 1개 쓰기·읽기 확인 성공, 재실행 미리보기 변경 0개.
  커밋·PR 후 작업 노트와 실제 PR 링크를 다시 동기화한다. 결과는 로컬 보고서에서 확인.
- 권한: 경로 검사로 스크립트의 대상을 제한하지만 OS 차원의 읽기 격리를 보장하지 않는다.
  외부 프로젝트 폴더 쓰기는 현재 샌드박스 승인 경계를 따른다.
