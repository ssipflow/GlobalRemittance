# PR 생성과 AI 리뷰 코멘트 테스트

요구: 지금 PR과 AI 리뷰를 테스트할 수 있는 작은 변경을 만든다.
범위: 실행되지 않는 예제 문서와 작업 기억. 저장소의 정책/에이전트 지침은 수정하지 않는다.

- 브랜치: dev에서 분기한 feature/pr-review-smoke.
- 리뷰 대상: 문서 속 수취액 계산 예제의 계약과 구현 차이.
- 검증: `git diff --check`; 애플리케이션 코드가 바뀌지 않으므로 앱 테스트는 실행하지 않는다.
- 완료 기준: dev 대상 PR 생성, AI가 작성한 리뷰 코멘트 게시 확인.
- 승인/병합: 사람이 수행. AI는 approve/merge/auto-merge를 실행하지 않는다.
- 로컬 AI 리뷰를 gh로 게시하는 것과 Codex GitHub 봇의 자동 리뷰 연결은 별도로 확인한다.

PR URL과 리뷰 게시 결과는 최종 답변 및 GitHub PR 이력으로 확인한다.
작성 시점에는 PR 생성 전이다. 원격 결과를 이 문서에 사후 반영하면 추가 커밋이
발생하므로 이번 PR의 GitHub 이력을 최종 증거로 삼는다.
