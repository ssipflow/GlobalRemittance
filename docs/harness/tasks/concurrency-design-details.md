# concurrency-design-details

- 요청: 간소화된 동시성 설명을 상세하게 보완한다.
- 변경: 주요 설계에 무잠금 경쟁·동일/서로다른 견적·잠금 경계·만료/자정 대기·대안·격리·조회 일관성·실패/재시도·테스트 근거를 추가한다.
- 실제 코드와 테스트를 대조하며 분석/현재구현/미검증범위를 구분한다. 앱 코드는 변경하지 않는다.
- 검증: 독립 문서 리뷰, fence/테스트명/변경범위 확인 및 diff 검사. 앱 테스트는 새로 실행하지 않는다.
- 종료: 하네스 커밋·dev PR, Vault 관리 구역에 동기화. 승인·병합은 사람.
